## 3. Discussion Notes
### 3.1 Topic 1 – Discuss Concerns About Current Dependencies
Clarify unit requirements:
- Confirm that the project must use JavaFX, MVC, JDBC, and SQLite as the core stack.
- Reaffirm that no REST APIs, no external databases, and no Spring Boot/Hibernate frameworks are required or expected.
  Review why Spring Boot, Hibernate, and other high-level frameworks may:
- Undermine learning outcomes (e.g., MVC, DAO, Singleton).
- Reduce opportunities to demonstrate understanding for assessment.
- Introduce “magic”/abstraction that replaces required manual implementation.
- Acknowledge that most group members are unfamiliar with these dependencies.
  Guidance from teaching staff:
- Lombok: Allowed for basic features (e.g., auto-generated getters/setters) as long as documented. But multiple team members are concerned that it will prevent us from learning.
- General rule: Any dependency is allowed IF it does not replace assessed learning outcomes or the required technologies.
- Tutors cannot provide support for frameworks outside the scope of the unit.

**Questions provided by DS to the group**
1. Have you tried using the current stack to extend functionality?
2. Have you read documentation from the libraries?
3. Do you have an alternative stack?
4. Do you have a test application implementing that alternative stack?
5. Have you compared the difference in usability and maintainability?

We need to decide as a team what technologies to implement before they are implemented.
