## Purpose of User Testing / Task
Tests whether user can confidently create, edit, and manage quizzes using the quiz template structure.
The focus areas are:
- Ability to create a quiz
- Ability to update or edit a quiz
- Ease of using the template structure
- Clarity of required fields: prompt, answers, tags, and correct answer
- Ease of categorisation and tagging
- Confidence that quizzes work as intended

---
## User Testing Tasks
User to complete the following tasks without guidance unless they become stuck.
1. Navigate to the quiz template / quiz creation area.
2. Create a new quiz using the template.
3. Add a quiz prompt/question.
4. Add multiple possible answers.
5. Select or mark the correct answer.
6. Add at least one relevant tag/category.
7. Save or submit the quiz.
8. Reopen the quiz and edit one field, such as the prompt, answers, tags, or correct answer.
9. Confirm whether the saved quiz appears to work as expected.

## Developer Notes
(For Emma to fill out after)
**Key issues found:**
Create Quiz button looks disabled in light mode.
Creating a category can go off-screen, making the confirm/save button hard to access.
After creating a quiz, user expected to be prompted to add questions immediately.
Quiz can be saved with only one question, but later fails when running because two questions are required.
First question may not save properly in that flow.
Category/tag wording caused minor confusion.
Users may be able to delete another user’s quiz.
Quiz completion sometimes leads to a blank page.
Question navigation becomes difficult when editing up to 10 questions.

**Positive feedback:**
Quiz creation was clear, familiar, and easy to understand.
Required fields were mostly clear and validation prevented incomplete quizzes.
Editing quizzes was intuitive and saved correctly.
Save notifications were clear.
User trusted that quizzes and correct answers were saved properly.
Results page was clear and useful.

**Suggested improvements:**
Make the Create Quiz button visually clearer/clickable, especially in light mode.
After quiz creation, automatically move the user into adding/editing questions.
Prevent quizzes from being saved unless the minimum number of questions is met.
Fix category creation modal/layout so buttons remain visible.
Clarify category vs tag wording.
Add permissions or confirmation around deleting quizzes.
Fix blank page after quiz completion.
Improve navigation between many questions during editing.

**Severity / Priority:**  
Medium
Core quiz creation works well, but several usability issues could confuse users or cause lost work. The one-question save/run issue and off-screen category button should be prioritised.
