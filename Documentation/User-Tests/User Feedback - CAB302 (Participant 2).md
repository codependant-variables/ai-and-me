### Q7.
**What roadblocks did you encounter when attempting to complete your required task?**

---
### Q8.
**How might the interaction be improved to help you achieve your task?**
*3 things:*
- *The UI should be scaled to the screen size and centered so it's easier to select elements and move to the next page.*
- *The home screen should detect if the user has started  a quiz before and if it does not, it should hide elements and show a quick start button.*
- *onboarding screens for the first time the user has used the app should be used to help survey the user and explain what the purpose of the app is and why.*
